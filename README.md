# C# Enumerations

## Specify an underlying type and explicit values
You can choose a different integral type and assign explicit values to control the numeric representation by inheriting from a different integral type (integer type).

## Bit Flags
Use the <code>[Flags]</code> attribute to be able to combine 2 or more enums.

## Parse strings and iterate values
The Enum base class provides methods for parsing strings and iterating over all defined values.
